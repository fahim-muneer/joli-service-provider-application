# Joli Service Booking

An online service booking marketplace connecting customers
with local service providers.

## Technology Stack

- Frontend: React + Vite
- Backend: Django REST Framework
- Database: PostgreSQL
- API Testing: Postman

## Architecture

Modular Monolith

## Main Modules

- Users
- Providers
- Locations
- Services
- Bookings
- Payments
- Invoices
- Commissions
- Notifications
